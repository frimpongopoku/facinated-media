# Extra photos

Drop photos here (JPG or PNG) that aren't on facinated.com: behind the scenes,
customers wearing your pieces, events, new work. Upload them from the GitHub app
or github.com: open this folder, then **Add file → Upload files**.

The file name is how you tell Claude what's in the photo, for example:

    ama-wedding-wearing-emerald-fascinator.jpg
    behind-the-scenes-making-bridal-pieces.jpg

Each Monday the weekly run looks here and works new photos into the posts.
Photos it has used are listed in USED.md so they aren't repeated too often.
